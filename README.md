# Shubham Kumar — Developer Portfolio

A responsive personal portfolio built with HTML, CSS, and a small amount of JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — dark theme, layout, responsive styling, and animations
- `script.js` — mobile navigation behaviour

## Run locally
1. Open this folder in Visual Studio Code.
2. Open `index.html` in a browser, or install the **Live Server** extension and choose **Open with Live Server**.
3. Edit the files, save, and refresh the browser if needed.

## Before publishing
- Check that the profile links are correct.
- Confirm you are comfortable displaying the email address publicly.
- Preview on desktop and mobile widths.
- Add completed projects when you have them; do not list unfinished work as completed.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new public repository named `shubham-portfolio` (or another name you prefer).
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under build/deployment, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for the Pages deployment to finish. GitHub will show the public website URL in the Pages settings.

The site is static, so it does not require a backend or database.
